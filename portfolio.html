01 / OVERVIEW

기획 의도

풀고 싶은 문제

반도체의 재료, 층 구조, 제조 과정은 설명만으로 연결해서 이해하기 어렵습니다. 사용자가 자신의 선택을 실제 화면의 변화와 연결할 수 있도록 체험 흐름을 설계했습니다.

제품의 접근

템플릿으로 시작하고, 재료와 구조를 조정한 뒤, 단계별 제조 과정을 관찰합니다. 완성된 칩은 회전·확대·단면·분해 보기로 탐색할 수 있습니다.

템플릿 선택→재료·구조 조정→장비 공정 재생→완성 칩 탐색
02 / EXPERIENCE

주요 기능

01

재료 커스터마이징

로직·센서·전력 칩 템플릿과 기판, 절연층, 배선, 패키지를 선택합니다. 템플릿에 따라 기판 선택을 제한하고, 두께와 배선 밀도를 조절할 수 있습니다.

02

직접 조작하는 3D 모델

드래그 회전과 휠 확대를 지원합니다. 외형, 층별 분해, 단면 보기로 칩의 전체 구조와 내부를 탐색합니다.

03

제조 장비 애니메이션

9개 공정에 로봇 이송, 증착 입자, 광학 스캔, 플라즈마 식각, 절단 휠과 패키지 조립을 연결했습니다. 단계 버튼을 눌러 원하는 장면을 재생합니다.

04

사용자가 조절하는 재생

일시정지와 재생, 0.25배부터 4배까지의 속도 슬라이더, 0.5·1·2·4배 빠른 선택을 제공합니다. 장비와 칩의 변화가 같은 진행률에 맞춰 움직입니다.

05

간결한 설정 화면

길게 나열된 설정을 접이식 항목으로 바꿨습니다. 선택한 값은 접힌 상태에서도 확인할 수 있고, 한 항목을 열면 이전 항목이 닫힙니다.

06

설계 보관과 결과 출력

설계를 브라우저에 자동 저장합니다. JSON 설계 파일과 PNG 칩 이미지 다운로드를 지원하며, URL에 설계 정보를 담아 같은 로컬 환경에서 복원할 수 있습니다.

03 / ENGINEERING

구현 구조와 기술 선택

HTML5CSS3Vanilla JavaScriptCanvas 2DrequestAnimationFramelocalStorage
설계 상태 → 선택값 검증 → 모델 형상·가상 점수 계산
공정 상태 → 단계 + 진행 시간 + 재생 속도 → 칩 변화·장비 동작
렌더링 → 3D 좌표 회전·투영 → 면 깊이 정렬 → Canvas 출력

외부 라이브러리 없는 3D 표현

JavaScript로 3차원 좌표를 회전하고 화면 좌표로 투영합니다. 면을 깊이순으로 정렬해 Canvas 2D에 그리는 방식으로 칩과 제조 장비를 구현했습니다.

시간 기반 애니메이션

requestAnimationFrame의 경과 시간에 재생 배율을 적용합니다. 공정 진행률이 장비 이동, 입자 효과와 층 생성에 함께 사용되므로 속도를 바꿔도 동작의 관계가 유지됩니다.

가상 특성 점수와 제조 장면은 교육용 표현입니다. 실제 성능 예측, 제조 주문, 계정 기반 클라우드 저장은 현재 구현 범위에 포함되지 않습니다.
04 / ITERATION

피드백을 반영한 개선

“화면이 너무 길다” → 클릭해서 펼치는 설정

모든 입력을 노출하던 화면을 항목별 접이식 구조로 변경했습니다. 특성 리포트도 접고 제목과 뷰어 높이를 줄였습니다.

“기계가 만들고 옮기는 과정도 보고 싶다” → 장비 중심 공정

칩 상태가 바뀌는 기본 시뮬레이션에 작업대, 이송 로봇, 공정 헤드와 입자 효과를 추가했습니다. 공정 시간을 늘려 동작을 관찰할 수 있도록 했습니다.

“제조 속도를 조절하고 싶다” → 전용 속도 패널

작은 선택 메뉴를 현재 배율 표시, 슬라이더와 빠른 선택 버튼이 있는 전용 영역으로 개선했습니다.

05 / VALIDATION & NEXT

확인한 동작과 다음 개선

현재 확인 범위

JavaScript 문법 검사와 로컬 페이지 응답을 확인했습니다. 브라우저에서 재료 변경, 제조 시작, 완성 화면 전환, 설정 펼치기, 장비 표시, 일시정지와 속도 버튼 반영을 확인했습니다. 사용자 대상 효과 측정과 정밀한 성능 벤치마크는 아직 진행하지 않았습니다.

다음 개선 방향

설계 파일 불러오기, 설계 간 비교, 공정별 설명 보강을 추가할 수 있습니다. 더 정교한 시각 표현을 위해 WebGL 렌더링을 검토하고, 사용자 테스트로 조작 이해도와 화면 구성을 개선할 계획입니다.
